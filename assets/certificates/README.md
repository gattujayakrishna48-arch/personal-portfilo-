# Certificates Directory

Place your certificate images (PNG, JPG) or PDF files in this folder.

### Example:
- `assets/certificates/google_cloud_ai_cert.pdf`
- `assets/certificates/be10x_cert.pdf`
- `assets/certificates/google_boost_bites.pdf`

To link to a certificate from `index.html`, update the `href` attribute on the corresponding certificate card's button:
```html
<a href="assets/certificates/google_cloud_ai_cert.pdf" target="_blank" rel="noopener noreferrer" class="btn btn-subtle btn-sm">
  View Certificate ↗
</a>
```
